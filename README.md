## 📖 项目介绍

> 上传一份带有空白内容的 Word 模板，LLMFill 自动完成 **文档解析 → 智能问答 → 内容填充** 完整链路：
> 自动识别文档内容，从私有知识库、联网搜索、大模型生成多渠道获取精准内容，
> 并**完整保留原有文档格式**将结果回写至 Word，字体、颜色、段落间距、样式和原始文档保持一致。

市面上传统AI文档填表工具，大多需要人工对文档做特殊标记；部分工具填充完成后文档格式错乱，交付前需要耗费大量时间手工调整返工。

LLMFill 聚焦解决最常见的业务场景：**直接处理现成带空白的 Word 业务模板**，核心做到：**免人工标记、填充格式不破坏**。

**完整使用文档**：[📚 查看说明文档](https://www.llmfill.com/docs)

## ✨ 功能特性

| 特性 | 说明 |
|-----------------|-------------------------------------------------|
| 🎯 **免标记占位符识别** | 智能自动识别文档空白位，无需手动插入标签、修改原模板 |
| 📚 **多来源精准答案** | 私有知识库RAG检索 + 联网搜索 + 大模型生成，多档答案来源可自由切换，内容可溯源 |
| 🎨 **格式保真写入** | AI生成内容回填Word，原始字体、颜色、间距、排版样式最大程度保留 |
| 📤 **双版本导出** | **标注复核版**（填充内容高亮标记，方便人工审核校验）+ **纯净交付版**（无高亮，可直接对外交付） |
| 📦 **批量文档处理** | 支持一次性上传多份Word模板，批量自动填充，打包压缩下载全部结果 |
| 🏢 **企业私有知识库** | 上传企业内部文档资料构建私有知识库，AI优先从内部资料提取答案，内置向量检索能力 |
| 🤖 **Agent Skill 调用** | 封装为 Agent Skill，Claude Code / Claw 等 AI Agent 一句话即可完成填表、建库、批量处理（详见 [skill/](skill/)） |

**典型应用场景**：投行尽调问卷（DDQ）｜律所合规审查评估表｜招投标响应文件｜HR入职表单｜咨询调研问卷｜政府项目申报材料｜高校科研项目申报书
